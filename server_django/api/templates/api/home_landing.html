Recursos do Pet Paparico

Tudo que você precisa para cuidar do seu pet com mais tranquilidade

📋 Cadastro Completo e Inteligente do Pet

Crie um perfil detalhado para cada um de seus pets com informações como nome, espécie, raça, peso, idade e notas pessoais. O sistema armazena fotos de alta qualidade e permite que você acompanhe o histórico de características físicas do seu animal ao longo do tempo.

💾 Tecnologia: Banco de dados PostgreSQL com suporte a uploads de mídia otimizados | 🔐 Segurança: Dados criptografados e backup automático

🍽️ Alimentação Manual, Agendada e Inteligente

Controle total sobre as refeições do seu pet. Alimente manualmente em qualquer hora com porções em gramas, configure agendamentos automáticos por horários específicos (matutino, vespertino, noturno) e escolha a frequência desejada (diária, dias úteis, fins de semana). O sistema permite múltiplos pets com reservatórios independentes, cada um com sua própria dosagem.

⚙️ Hardware: Servo motor de precisão controlado via ESP32 WROOM-32D | 📡 Comunicação: APIs RESTful com sincronização em tempo real | 📊 Precisão: Dispensador calibrável para porções de 10g a 500g

📊 Histórico Inteligente e Análise de Comportamento

Acompanhe cada refeição realizada com timestamp preciso, identifique padrões de alimentação e hábitos do seu pet. Visualize gráficos de frequência, quantidade consumida por período e tendências ao longo de semanas e meses. Essas informações são fundamentais para detectar mudanças no comportamento e alimentação que possam indicar problemas de saúde.

📈 Análise: Gráficos dinâmicos com filtros por período (dia, semana, mês, ano) | 🧮 Estatísticas: Média de refeições, quantidade total dispensada, frequência e padrões | 📱 Visualização: Interface responsiva com suporte a múltiplos dispositivos

🎥 Monitoramento em Tempo Real e Controle do Dispositivo

Monitore continuamente o estado completo do dispensador: nível de ração em percentual, status de conexão (online/offline), nível de bateria, sinal WiFi (RSSI) e temperatura do ambiente. Integre câmeras RTSP para visualizar o local onde seu pet se alimenta. Teste a conexão do ESP32 e calibre manualmente o servo motor para garantir precisão nas dispensações.

📡 Hardware: ESP32 WROOM-32D com WiFi integrado e suporte a múltiplos sensores | 🎥 Câmeras: Compatível com feeds RTSP (IP cameras, webcams, baby monitors) | 🔧 Ferramentas: Interface de calibração em tempo real com visualização do servo motor | ⚡ Status: Atualizações contínuas do estado do dispositivo

🔔 Sistema Inteligente de Notificações e Avisos Personalizados

Receba notificações automáticas para eventos importantes: quando a alimentação é completada com sucesso, quando o nível de ração cai abaixo do limite configurado, quando o dispositivo fica offline, ou lembretes personalizados. Configure preferências por tipo de notificação (email, push notifications) e defina thresholds de ração que façam sentido para seu pet.

📧 Canais: Email e notificações push inteligentes (configuráveis por tipo) | 🎯 Customização: Defina limiares de ração baixa e tipos de eventos | ⏰ Confiabilidade: Notificações garantidas com registro de entrega | 🚨 Urgência: Alertas prioritários para problemas críticos (offline, ração baixa)

♿ Acessibilidade Inclusiva e Conformidade WCAG

Desenvolvido com preocupação genuína na inclusão. A interface foi construída seguindo as diretrizes WCAG 2.1 nível AA para acessibilidade web, conta com suporte a leitores de tela (NVDA, JAWS), navegação por teclado completa, contraste adequado entre cores, e foi testado com usuários reais que possuem diferentes necessidades.

🧑‍🦯 Conformidade: WCAG 2.1 AA (Web Content Accessibility Guidelines) | 🗣️ Linguagem: Suporte a leitura de tela e navegação por teclado | 🎨 Design: Contraste elevado, texto ampliável, modo escuro | 📖 Documentação: Guia de acessibilidade e compatibilidade com tecnologias assistivas

🚀 STACK TECNOLÓGICO

Backend: Django 6.0.4 com Django REST Framework para APIs robustas | Banco: PostgreSQL com ORM Django para integridade de dados | Frontend: HTML5, Tailwind CSS e JavaScript vanilla para performance | Hardware: ESP32 WROOM-32D com firmware em C++ | Deployment: Preparado para produção com HTTPS, CORS configurado e rate limiting
